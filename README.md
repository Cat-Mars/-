# 喵喵 🐾

你家自己的猫，趴在 Windows 桌面上。

- 一只猫，不换角色、不加戏
- 鼠标移到猫身上才抓得住，点别处照样点桌面图标（不会挡你）
- 按住拖着跑 → 眯眼冒 ♥，喵一声
- 不管它 → 打个哈欠，然后睡着冒 z
- 右键：**开启 / 关闭 / 退出**
- 单 exe，零 DLL，不弹管理员，不用安装

## 自己出 exe（电脑上什么都不用装，Win11 自带编译器）

解压后双击 `烤.bat`，黑框闪一下，`喵喵.exe` 就出来了。

手动也行：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /unsafe /out:喵喵.exe 喵喵.cs
```

> 万一提示找不到 `csc`：设置 → 应用 → 可选功能 → 安装「.NET Framework 4.x 开发工具」，再双击 `烤.bat`。

## 懒得编译

点仓库顶上 **Actions** → 最新的 `构建喵喵.exe` → 底部 Artifacts 里下载 `喵喵`，解压就是 `喵喵.exe`。

猫图换法：拿正脸侧坐的猫图覆盖 `喵喵.png`（要透明背景，PNG），重新双击 `烤.bat`。
